属性配置：自动生成枚举 + IAttrBag 接口

v3 枚举驱动 不再手写 key 字符串：目录→生成 enum AttrKey + 接口化 AttrBag 访问
目录 = 一堆属性（不管归属）；组合 = 编辑器勾选的数据（不生成代码）。 这页重点在右下：框架从目录自动生成的枚举 + 接口。

属性目录（全量，扁平）

每条一个属性。加/改后，右下生成的 enum 会同步。

key类型默认minmax显示名

角色组合（编辑器勾选 = 数据）

自动生成：enum AttrKey


      
自动生成：AttrBag（实现框架 IAttrBag）

      

      
框架侧一次性提供（手写，不生成）

      
public interface IAttrBag
{
    int  GetInt (AttrKey k);
    void SetInt (AttrKey k, int v);
    float GetFloat(AttrKey k);
    void SetFloat(AttrKey k, float v);
    bool GetBool (AttrKey k);
}

    

  

  
工作流： 目录(Excel→AttributeDef 行) → 编辑器勾选组合(数据) → 框架 codegen 出 enum AttrKey + AttrBag。代码里 new AttrBag(em, e).GetInt(AttrKey.ATK)，全程枚举，零手敲字符串。






  
不推荐：手写 key 字符串（你要去掉的）

  
int atk = AttributeStore.GetInt(em, hero, "ATK");   // 拼错只能运行期发现
AttributeStore.SetInt(em, hero, "ATK", atk + 10);


  
推荐：枚举 + 接口（自动生成）

  
// 自动生成的 enum + AttrBag（见编辑 tab）
var attrs = new AttrBag(em, hero);
int  atk = attrs.GetInt(AttrKey.ATK);     // 枚举：IntelliSense，拼错编译期报错
attrs.SetInt(AttrKey.ATK, atk + 10);       // 越界内部钳制
float spd = attrs.GetFloat(AttrKey.MoveSpeed);
