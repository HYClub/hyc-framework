# 81 · BT 编辑器：画布与资源面板

> 打开：`Tools/HYC/BT Editor`（`BTGraphWindow`）
> 实现：`Editor/BT/BTGraphIMGUI.cs`（NodeCanvas 风格 IMGUI 全手绘，零依赖 NodeCanvas/ParadoxNotion）

---

## 界面布局

```
┌──────────────────────────────────────────────────────┐
│ 工具栏                                                │
├───────────┬──────────────────────────┬───────────────┤
│ 行为树资源 │          画布             │ Explorer(ROOT) │
│ （左栏）   │   ┌──────────────┐       │ 黑板           │
│ 目录树     │   │ 节点库(浮动)  │       │ 运行时         │
│ ＋新建树   │   └──────────────┘       │               │
│ ＋新建目录 │        [minimap]          │               │
├───────────┴──────────────────────────┴───────────────┤
│ 底栏：校验结果 / 选中信息                              │
└──────────────────────────────────────────────────────┘
```

- **左栏**：行为树资源列表（独立滚动）
- **中间**：画布（节点、连线、minimap 在右下）
- **右栏**：Explorer（树形结构，点行可 Ping 画布节点）+ 黑板 + 运行时
- **节点库**：画布上的浮动窗口，标题栏可拖动，可关闭

---

## 画布操作

| 操作 | 效果 |
| --- | --- |
| **中键拖动** | 平移画布 |
| **滚轮** | 缩放 |
| **左键拖空白** | 框选（多选） |
| **左键拖节点** | 移动选中节点 |
| **从输出端口拖到输入端口** | 建立连线 |
| **右键节点** | 节点菜单（装饰 / 替换 / 转子树 / 复制分支 / 删除分支） |
| **右键画布** | 创建节点 |
| **`Delete`** | 删除选中节点（`Root` 不可删） |
| **拖动节点库条目到画布** | 创建节点（也可直接点击条目创建在中心） |

节点上的参数可 **inline 直接编辑**（不用开 Inspector）。

### 端口约定
- 每个节点 **1 个输出端口**（右缘，垂直居中）、**1 个输入端口**（左缘，垂直居中）
- `End` 节点没有输出端口
- **连线的 `PortIndex` 决定子节点执行顺序**（对 `Sequence` 尤其重要）

## 资源面板（左栏）· Windows 文件列表风格

### 目录树

- 文件夹可**无限嵌套**，点击行首的 `▸ / ▾` 展开折叠
- 目录内先显示子目录、再显示行为树资产

### 新建

面板顶部两个按钮：

```
＋ 新建树      ＋ 新建目录
新建于 ▸ BTTrees（根）
```

**新建落在"当前选中项"所在目录**（选中目录 → 建在里面；选中资产 → 建在其父目录；没选 → 建在根）。
新建后会**自动进入改名状态**（和 Windows 一样）。

### 选中与改名

| 操作 | 效果 |
| --- | --- |
| 单击 | 选中该行 |
| **对已选中行再单击一次** | 进入改名（全选文本） |
| `F2` | 对选中项改名 |
| `Enter` | 提交改名 |
| `Esc` | 取消改名 |
| 点击改名框以外 | **提交**改名 |
| 双击资产 | 打开该树 |
| 双击文件夹 | 展开 / 折叠 |

> 改名判定与 Unity Project 窗口一致：两次单击间隔 < 0.4s 视为双击，≥ 0.4s 视为"再点一次改名"。

### 拖拽移动

- 按住行拖动（超过 4px 才起拖），跟随鼠标显示拖拽幽灵
- **拖到文件夹行上** → 该行蓝色高亮 = 移入这个目录
- **拖到资产行上** → 移入它所在的目录
- **拖到空白** → 移到根 `Assets/BTTrees`
- 拖到面板上下边缘会**自动滚动**

安全规则：
- 同目录不会触发移动
- **不能把文件夹拖进它自己或它的子文件夹**（会 `LogWarning` 拒绝）
- 根目录 `Assets/BTTrees` 不可移动
- 同名冲突自动改名（`GenerateUniqueAssetPath`）
- **也支持从 Unity Project 窗口把 `.asset` 拖进来**

### 右键菜单

- 资产：打开 / 重命名 / 在 Project 窗口中显示 / 删除
- 文件夹：新建行为树 / 新建子文件夹 / 重命名文件夹 / 在 Project 窗口中显示 / 删除文件夹

## 底栏

显示 `BTValidator` 的校验结果（例如"2 个节点未连接（孤立）"）与当前选中信息。
导出前建议先看这里——**有孤立节点不会阻断导出，但通常意味着逻辑漏了**。

---

## 导出与自动注册

- 工具栏可手动构建并注册 Blob（成功/失败都有日志）
- **进入 Play 模式会自动构建并注册**所有树（`BTAutoRegisterOnPlay`），无需手动导出

---

## 注意事项 / 坑

1. **资产行是"双击打开"，不是单击打开**——单击只是选中（并决定新建落点）。
2. **改名时点击别处是"提交"不是"取消"**（对齐 Windows；与部分 Unity 原生行为不同）。
3. **折叠三角是独立命中区**（行首 16px），点它只展开折叠、不会触发改名。
4. **移动/改名资产不影响运行期引用**——运行期按 `TreeId` 查找，但**改 `TreeId` 会断引用**。
5. 画布**不做 GUIClip 裁剪**，靠"画布先画、面板后画覆盖"隐藏越界内容——如果你新增面板/chrome，务必画在画布之后，否则节点会画到面板上面。
