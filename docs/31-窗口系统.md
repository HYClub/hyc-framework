## 一、写一个窗口

```csharp
using HYC.Framework.UI;

public class BagWindow : BaseWindowSystem<BagBinder>   // 泛型参数 = 生成的绑定类
{
    // Addressables 预制体 key（必填，abstract）
    public override string PrefabKey => "UI/BagWindow.prefab";

    // 可选：需要先加itively 加载的 UI 场景
    public override string SceneKey => "Scene_UIBag";

    // 可选：层内排序（默认 0，升序）
    public override int Order => 10;

    // 可选：是否参与焦点（BaseWindowSystem 默认 true）
    public override bool Focusable => true;

    // 视图加载完成后调用（异步！）
    public override void OnViewOpen(params object[] args)
    {
        base.OnViewOpen();
        Binder.CloseButton.onClick.AddListener(OnClose);   // Binder 在这里才可用
    }

    public override void OnViewUpdate() { /* 每帧 */ }

    public override void OnViewClose()
    {
        UnregisterHotkey(mHotkey);
        base.OnViewClose();
    }
}
```

打开：

```csharp
UIManager.OpenWindow<BagWindow>(1001, "equip");   // params 会透传到 OnViewOpen(args)
UIManager.Close<BagWindow>();
bool open = UIManager.IsOpen<BagWindow>();
```

## 二、可重写的成员

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `PrefabKey` | `abstract string` | **必填**，Addressables key |
| `SceneKey` | `virtual string` | 默认 `string.Empty`；非空则先加itively 加载该场景 |
| `Order` | `virtual int` | 层内排序，默认 0 |
| `Focusable` | `virtual bool` | 默认 `true`；`BaseHudSystem`/`BaseLoadingSystem` 覆写成 `false` |
| `OnSceneOpen(Scene)` / `OnSceneOpen(Scene, args)` | virtual | UI 场景加载完成（仅 `SceneKey` 非空） |
| `OnViewOpen(args)` / `OnViewOpen()` | virtual | **视图就绪**，初始化写这里 |
| `OnViewUpdate()` | virtual | 每帧（`View != null` 时） |
| `OnViewClose()` | virtual | 关闭时；基类会 `Disable()` + 注销热键 + 关闭所有 Part |
| `OnViewFocus()` / `OnViewLost()` | virtual | 焦点变化；基类负责热键静默开关 |
| `OnViewLayerChanged(int sortingOrder)` | virtual | 层级重算后回调，值存进 `ViewSortingOrder` |
| `OnAnimationEvent(string key)` | virtual | 动画事件；`"Enter"` / `"Exit"` 由框架自动发 |
| `Hide()` / `Show()` | virtual | 只改 `_targetAlpha`（0/1） |

### 可用的属性

| 属性 | 说明 |
| --- | --- |
| `View` | 实例化的预制体根（未加载完为 null） |
| `Canvas` | 运行时创建的 WorldSpace Canvas |
| `Camera` | `Canvas.worldCamera` |
| `CanvasGroup` | 需自行赋值，框架不自动加 |
| `ViewSortingOrder` | 最近一次 `OnViewLayerChanged` 给的 sortingOrder |
| `UISystemType` | `Normal` / `Single`，由 `UIManager.Open` 写入 |
| `Focused` | `protected`，`Focusable && UIManager.FocusedWindow == this` |

## 三、窗口部件（WindowPart）

可复用的子界面，本身也是 `SystemBase`，挂在父窗口节点下。

```csharp
public class BagItemPart : BaseWindowPart<BagItemBinder>
{
    public override string Key => "UI/BagItemPart.prefab";   // null 时必须用带 GameObject 的重载

    public override void OnViewOpen() { /* 绑定、注册事件 */ }
    public override void OnViewUpdate() { }
    public override void OnViewClose() { base.OnViewClose(); }
}
```

父窗口里开：

```csharp
var part = OpenWindowPart<BagItemPart>();                       // 挂到 View 根
var part2 = OpenWindowPart<BagItemPart>(someTransform);         // 指定父节点
var part3 = OpenWindowPart<BagItemPart>(existingGameObject);    // 直接用已有对象（不加载）
part3.Close();                                                  // 触发 CloseHandler
```

四个重载：

| 重载 | 行为 |
| --- | --- |
| `OpenWindowPart<T>()` | 用 `Key` 加载，挂到 `View.transform` |
| `OpenWindowPart<T>(Transform parent)` | 用 `Key` 加载，挂到指定 parent |
| `OpenWindowPart<T>(GameObject go)` | **不加载**，直接用该对象，挂到 `View.transform` |
| `OpenWindowPart<T>(Transform parent, GameObject go)` | 不加载，挂到指定 parent |

- `BaseWindowPart` 也能再开子 Part（同样的四个重载），可嵌套。
- 关闭父窗口时 `CloseAllWindowPart()` 自动递归关闭所有 Part。
- Part 的 `Loaded` 标志表示视图是否已就绪。

⚠️ 若 `Key` 为 null 且没传 GameObject → `LogError($"打开 {type.Name} 失败 : WindowPart 既未设置 Key, 也未指定界面对象")`，但**仍然返回了 system 实例**，且它的 `View` 是 null。

## 四、子窗口（AbsParentBaseWindowSystem）

需要在一个窗口里嵌入另一个**完整窗口系统**时用：

```csharp
public class MainHubWindow : AbsParentBaseWindowSystem<MainHubBinder>
{
    public override string PrefabKey => "UI/MainHub.prefab";

    public override void OnViewOpen()
    {
        base.OnViewOpen();
        Open<BagWindow>(Binder.BagSlot);   // 参数是 RectTransform 容器
    }

    protected override void OnUpdate() { }
}
```

- `Open<T>(RectTransform parent, params object[] args)`：加载预制体 → 改名 `(Clone)` → `(SubWin)` → 挂到 parent → 拉伸对齐（`anchoredPosition3D = 0`、`offsetMin/Max = 0`、`localScale = 1`）→ `OnViewOpen(args)`。
- `IsOpened(window)` 判断子窗口是否还开着。
- 父窗口 `OnViewClose` 会**自动关闭所有子窗口**。

⚠️ 子窗口**不走 `UIManager` 的层管理**——没有 Canvas、没有 sortingOrder、不进 `LayerViews`，所以不会有焦点/层级/HUD 隐藏那些行为。它只是"挂在父窗口节点下的另一个 System"。

## 五、热键注册

```csharp
private HotkeyHandle mHotkey;

public override void OnViewOpen()
{
    // 最简单：动作名 + 回调
    mHotkey = RegisterHotkey(HotkeyActionNames.UI_UGUI_Cancel, ctx => UIManager.Close<BagWindow>());

    // 带长按（< 0.1 会被钳到 0.1，NaN 也变 0.1）
    RegisterHotkey("Game/UseItem", OnUse, holdTime: 0.5f);

    // 带 UI 提示元素（会在 parent 下生成按键提示 UI）
    RegisterHotkey("Game/UseItem", someHotkeyElement, OnUse, priority: 10);

    // 自定义样式 + 文本
    RegisterHotkey("Game/UseItem", OnUse, Binder.HotkeyRoot, "使用", HotkeyElementStyle.UI, 5);
}
```

- 所有重载都会把 handle 存进内部 `_hotkeys` 列表。
- **`OnViewClose()` 自动 `UnregisterAllHotkey()`**——只要没忘调 `base.OnViewClose()`。
- 失焦时框架把所有热键 `Silence = true`（`OnViewLost`），得焦恢复 `false`。
- 手动注销：`UnregisterHotkey(handle)`。

⚠️ `AbsUISystem.Enable()/Disable()` 会额外注册/注销四个导航热键 `UI_UGUI_Horizontal/Vertical/Submit/Cancel`——这两个方法由基类在 `OnViewOpen`/`OnViewClose` 里按 `Focusable` 自动调用，**不要手动调**。

## 六、组件查找

不想用生成 Binder 时，可以按路径找：

```csharp
protected T FindComponent<T>(string path);            // 相对 View
protected T FindComponent<T>(Component node, string path);  // 相对某个节点
```

例：`var label = FindComponent<TMP_Text>("Root/Left/Name");`

⚠️ 用的是 `Transform.Find`，**路径必须完整且大小写一致**，找不到返回 null（不报错）。

## 七、焦点导航（手柄/键盘）

框架自带完整实现，一般不用改。要点：

- **只在 `HotkeyManager.IsNavigateMode` 时生效**（鼠标键盘模式直接跳过）。
- 首次选中：`FindFirstSelection()` —— 先找 `FocusableCustom`，再找**可交互且 `navigation.mode != None`** 的 `Selectable`。
- 移动：`FindNextFocusBy(current, dir)`
  - `TMP_InputField` / `InputField` → 不移动（输入框内导航）。
  - `FocusableCustom` → 调它的 `OnMove(dir)`。
  - `Navigation.Mode.Explicit` → 直接取 `selectOnLeft/Up/Right/Down`。
  - 其它 → 走**几何打分**：`value = Dot(dir, 目标中心 - 参考点) / 距离平方`，取最大。
- 连发节流：见 [30 篇](./30-ECS-UI-总览.md) 的参数表。
- `AutoSelectOnGotFocus` 挂到对象上：导航到它时会**自动触发一次 Submit**。

自定义导航就继承 `AbsUISystem.FocusableCustom` 并重写 `OnMove(MoveDirection dir)` 返回目标 GameObject。

## 九、动画钩子

预制体根上挂 `UIAnimationHook`（`[RequireComponent(typeof(Animator))]`），Animator 的 Animation Event 调用：

| 方法 | 触发 |
| --- | --- |
| `FireAnimationEnterEvent()` | → `window.OnAnimationEvent("Enter")` |
| `FireAnimationExitEvent()` | → `window.OnAnimationEvent("Exit")` **然后自动 `Close(window, false)`** |
| `FireAnimationEvent(string key)` | → `window.OnAnimationEvent(key)` |

关闭时 `UIManager` 会先找 Animator 的 `"Exit"` **Trigger** 并 SetTrigger；所以**退出动画要靠 Animator 参数 `Exit`（Trigger 类型）+ 末尾的 Animation Event 调 `FireAnimationExitEvent`** 串起来。

## 十、注意事项 / 坑

1. **别在 `OnCreate` 里碰 `View`**——`OnCreate` 在 System 首次创建时跑，此时预制体还没实例化，甚至窗口还没被 Open 过。
2. **`OnViewClose` 一定要 `base.OnViewClose()`**——否则热键不会注销、Part 不会关闭、`Enable/Disable` 不配对。
3. **`Binder` 是懒构造的**：首次访问 `Binder` 时才 `new T()` + `Reset(View)`。`OnViewClose` 里会置 `default`（下次重新绑定）。所以**不要在 `OnViewOpen` 之前访问 Binder**（会绑到 null View 上）。
4. **`CanvasGroup` 不会自动创建**——需要淡入淡出就自己在预制体上放一个，并在 `OnViewOpen` 里赋给 `CanvasGroup` 属性。
5. **`UISystemType.Single` 只对 HUDNotice 路径生效**（`LoadPrefabBegin` 里判断后 `CloseHudNotice(SingleUISystem)`），全局只有一个 `SingleUISystem` 槽位。
6. **`IsOpen<T>()` 看的是 `window.Enabled`**，异步加载中返回 false；要"加载中也算开着"用 `IsOpenAsync(Type)`。
7. **`OpenWindowAndCloseOther<T>()` 只关 `Window` 层**且跳过同类型。
8. **窗口 System 是 `GetOrCreateSystemManaged` 复用实例**——关闭后 System 对象仍在 World 里，字段值不会重置。**下次打开前务必在 `OnViewOpen` 里重新初始化所有状态字段**。
