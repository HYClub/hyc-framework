# 91 · 设置窗口：配置式分组（HYC Settings）

> **一句话**：给**字段**或**无参 void 方法**加一行 `[HYCSettingsGroup("分组/子分组")]`，
> 它就出现在 `HYC Framework/Settings/Project Settings` 窗口里。
> **窗口里没有写死任何分组清单**——加/删/改分组只改那一行的特性字符串。

> 适用版本：`com.hyc.framework` v2.0.4+（Unity 2022.3）。相关源码：
> `Editor/HYCSettingsGroupAttribute.cs`、`Editor/HYCSettingsRegistry.cs`、`Editor/HYCSettings.cs`、`Editor/HYCEditorSettingsWindow.cs`
> （均在命名空间 `HYC.Framework.Editor`，Editor 程序集内，运行时不存在）。
>
> **存储**：所有设置值落工程内 **`Assets/HYC/HYCSettings.asset`**（纯 ScriptableObject，见 [②-bis](#存储hycsettings-资产)）——
> 随工程进版本控制，多人协作共享同一份设定；不再是本机 EditorPrefs。

---

## ① 架构：声明 → 扫描 → 绘制

```
① 声明（你的代码）          ② 扫描（注册表，域内缓存）        ③ 绘制（窗口）
─────────────────────      ──────────────────────────      ─────────────────────
[HYCSettingsGroup]   ──▶   HYCSettingsRegistry             HYCEditorSettingsWindow
  字段 → 自动控件              反射扫描程序集                     左栏：分组树（200px）
  方法 → 自定义绘制            拼成分组树 Node/Item                右栏：选中分组的条目
                              字段自动存取 HYCSettings 资产        选中态按 Path 记忆
```

| 环节 | 谁负责 | 关键事实 |
| --- | --- | --- |
| 声明 | 使用方（框架内或宿主工程） | 路径用 `/` 表示嵌套：`"Audio/Backend"` |
| 扫描 | `HYCSettingsRegistry` | 只扫**引用了 `HYC.Framework.Editor` 程序集**的程序集；结果按域缓存，`Rebuild()` 可强制重建 |
| 绘制 | `HYCEditorSettingsWindow` | 左栏递归画行、右栏递归画页；选中页存 `[SerializeField] _selectedPath`，域重载不丢 |

**分组树语义**：路径 `A/B/C` → 节点 `A` 下有 `B`，`B` 下有 `C`。
分组名 = 路径末段（要中文就写中文，要英文就写英文，**改特性字符串即可**）。
右栏显示「本组自己的条目 + 各子分组作为子标题依次展开」，所以**点父分组能一次看到全貌**（这是设计，不是重复渲染的 bug）。

## ② 关键类

| 类型 | 文件 | 职责 |
| --- | --- | --- |
| `HYCSettingsGroupAttribute` | `Editor/HYCSettingsGroupAttribute.cs` | 声明「这个成员属于哪个分组」。`AttributeTargets.Method \| Field`，不可重复标注 |
| `HYCSettingsRegistry` | `Editor/HYCSettingsRegistry.cs` | 反射扫描 → 分组树；字段自动绘制与持久化（读写 `HYCSettings` 资产条目）。嵌套类型 `Node`（分组节点）/ `Item`（条目） |
| `HYCSettings` | `Editor/HYCSettings.cs` | **设置资产本体**（SO）：具名字段 + 键值条目表，所有写操作立即落盘 |
| `HYCEditorSettingsWindow` | `Editor/HYCEditorSettingsWindow.cs` | Unity Preferences 式两栏窗口；`RegisterHost(this)` 登记自身，故窗口内的私有成员也生效 |

### 特性参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `Path`（构造参数，**必填**） | — | 分组路径，`/` 分隔。空串/纯分隔符会被忽略并告警 |
| `Label` | 成员名易读化（去掉前导 `_`、驼峰拆词，如 `_autoGen` → `Auto Gen`） | 字段=左侧标签；方法一般留空（方法自己画） |
| `Order` | `0` | 同组内排序（升序），再按标签兜底 |
| `Key` | 自动 `HYC.Framework.Settings.<类型全名>.<字段名>` | 字段持久化**条目键**（存于 `HYCSettings` 资产的键值表）。**稳定后建议显式指定**，改名/换类型才不会丢已存的值 |
| `Persist` | `true` | 字段改动是否写入 `HYCSettings` 资产 |

### 存储：HYCSettings 资产

```
Assets/HYC/HYCSettings.asset        ← 约定路径（ScriptableObject，ns HYC.Framework.Editor）
```

| 问题 | 答案 |
| --- | --- |
| 为什么不用 EditorPrefs | 只存本机（注册表 / plist）：不进版本控制、多人协作不同步、换机即丢 |
| 资产怎么被找到 | 先按约定路径 `LoadAssetAtPath`；找不到再全工程搜 `t:HYCSettings`（移走也能用）；都没有则就地创建 |
| 什么时候落盘 | 每次写操作（属性 setter / `SetEntry`）立即 `SetDirty + SaveAssetIfDirty`——设置是低频操作，不需要延迟保存 |
| 字段值存哪 | 两条路：① 具名字段（配置数据编辑器全项、音频后端）走 SO 序列化字段；② `[HYCSettingsGroup]` 字段走**键值条目表**（平行 `List<string>`，bool/int/float/string/枚举统一转字符串，写入与解析严格配对） |
| 旧 EditorPrefs 值会丢吗 | 会——但这是有意为之：SO 是新的存储，首次打开用代码默认值建资产，不需要迁移（迁移只会把本机值带进团队仓库） |
| 想让运行时也读到 | 不行，这是**编辑器**资产。运行时设置走 `Runtime/Settings.cs`（`FrameworkSettings`，落 `Assets/Resources`）或配置表 |

## ③ 用法

### 场景 1：加一个开关 / 数值 / 文本 / 枚举（字段，零绘制代码）

```csharp
using HYC.Framework.Editor;

namespace MyGame.Editor
{
    internal static class MyGameSettings
    {
        // 顶层分组 General，标签自动出 "Verbose editor logs"
        [HYCSettingsGroup("My Game", Label = "Verbose editor logs")]
        internal static bool Verbose = true;

        [HYCSettingsGroup("My Game", Label = "Max entity hint", Order = 10)]
        internal static int MaxEntityHint = 2000;

        [HYCSettingsGroup("My Game", Label = "Remote host")]
        internal static string RemoteHost = "127.0.0.1";

        // 自定义枚举字段 → 自动出 EnumPopup（框架内置音频分组已改为数据驱动：见 FrameworkSettings.audioGroups）
        [HYCSettingsGroup("My Game", Label = "Default channel")]
        internal static GameChannel DefaultChannel = GameChannel.Sfx;

        internal enum GameChannel { Sfx, Music, Voice }
    }
}
```

字段类型支持：`bool` / `int` / `float` / `string` / **枚举**（分别为 Toggle / IntField / FloatField / TextField / EnumPopup）。
改动**即时写入** `HYCSettings` 资产，不需要点保存按钮。

### 场景 2：自定义区块（方法，按钮 / 下拉 / 提示框）

```csharp
[HYCSettingsGroup("My Game/Tools")]
internal static void DrawTools()
{
    if (GUILayout.Button("Rebuild All Configs"))
        MyGameConfigTools.RebuildAll();

    EditorGUILayout.HelpBox("会在 Console 输出逐表耗时。", MessageType.Info);
}
```

方法约束：**无参 `void`**（实例或静态都行）。签名不对会 `Debug.LogWarning` 并忽略，不会编译报错。
方法内部就是普通 IMGUI，想画什么画什么。

### 场景 3：嵌套分组

```csharp
[HYCSettingsGroup("Audio/Backend")]  static void DrawBackend() { /* … */ }
[HYCSettingsGroup("Audio/Bus")]      static void DrawBus()     { /* … */ }
```
左栏出现：`Audio`（缩进 0）→ `Backend`、`Bus`（缩进 1）。点 `Audio` 右栏一次性看到两个子分组。

### 场景 4：实例成员（窗口内的私有方法）

窗口已在 `OnEnable` 调 `HYCSettingsRegistry.RegisterHost(this)`，所以**窗口内的私有字段/方法直接可用**：

```csharp
[HYCSettingsGroup("ID Server")]        // 框架自带示例
private void DrawIdServerSection() { /* … */ }
```

**窗口之外的类**：要么用 `static`（推荐，见场景 1），要么自己登记宿主：
```csharp
HYCSettingsRegistry.RegisterHost(myObject);    // OnEnable 里
HYCSettingsRegistry.UnregisterHost(myObject);  // OnDisable 里
```
未登记的实例成员**不会被扫描**（注册表不会随手 `new` 出编辑器对象）。

### 现有内置分组（照抄样例）

| 左栏分组 | 实现 | 形式 |
| --- | --- | --- |
| `General` | `_verbose` / `_autoGen` 两个 bool 字段 | 字段（自动控件，Key 沿用历史键名） |
| `CodeGen` | `DrawGeneratedNamespaceRootSection()` | 方法（root 输入框 + 生效 root / 配置 / BT 三行预览） |
| `ID Server` | `DrawIdServerSection()` | 方法（状态灯 + 下拉 + 按钮 + 条件 HelpBox） |
| `Audio` | `DrawAudioBackendSection()` | 方法（后端下拉 + 三态提示框） |
| `Validation` | `DrawValidators()` | 方法（一个按钮） |

> 命名惯例：分组名用**英文**（与 `HYC Framework/` 菜单保持同一种语言）。
> 想换中文只需改特性字符串，不涉及任何逻辑改动。

## ④ 坑（雷区）

| # | 现象 | 原因 / 处理 |
| --- | --- | --- |
| 1 | 加了特性，左栏不出现 | ① 所在程序集**没有引用** `HYC.Framework.Editor`（注册表只扫引用了它的程序集）；② 是实例成员但宿主没 `RegisterHost`；③ 结果已缓存，改完触发一次域重载或调 `HYCSettingsRegistry.Rebuild()` |
| 2 | 方法被忽略并告警 | 签名必须是**无参 `void`**；泛型方法同样不支持 |
| 3 | 字段出黄色提示框 | 类型不在 `bool/int/float/string/enum` 之内。要复杂控件 → 改用方法自己画 |
| 4 | 升级后旧设置值被冲掉 | 未显式 `Key` 时键由「类型全名 + 字段名」生成，改名即换键。**稳定后显式指定 `Key`** |
| 5 | 分组名里的斜杠被切成两层 | 路径里的**半角 `/` 是分隔符**。名字本身要带斜杠请用全角 `／`（同 `EditorGUI.Popup` 那条坑：半角 `/` 会被当子菜单分隔符） |
| 6 | 点父分组看到的内容与子页重复 | 设计如此：父页 = 本组条目 + 子分组子标题，便于一次看全貌 |
| 7 | 窗口偶尔报 `Invalid GUILayout state` | 绘制方法里**按状态增删控件**导致 Layout/Repaint 两阶段控件数不一致。条件分支要始终画、只换文案或套 `EditorGUI.DisabledScope` |
| 8 | 排序不合预期 | 分组固定按名称排序；条目按 `Order` 再按标签。要指定顺序就填 `Order` |
| 9 | 静态字段在 Editor 重启后回到默认值 | 检查 `Persist` 是否被改成 `false`，或 `Assets/HYC/HYCSettings.asset` 被删/被 git 还原（SO 进版本控制，本地删了就会回到默认值） |
| 10 | 想把设置给运行时用 | 本窗口是**编辑器**设置（资产在 Editor 程序集）。运行时设置走 `Runtime/Settings.cs` / 配置表，不要混用 |
| 11 | 设置资产出现在 git 变更里 | **设计如此**：它就是拿来共享的。不想共享某项就设 `Persist = false`（只活在本机内存） |

## ⑤ 验证清单

1. `HYC Framework/Settings/Project Settings` 打开窗口 → 左栏应出现新分组，缩进与 `/` 层级一致。
2. 点分组 → 右栏出现条目；改一个值 → 关闭窗口、重开，值仍在（说明持久化条目生效）。
3. 改完值后 `Assets/HYC/` 下应出现 `HYCSettings.asset`（git 里能看到它的变更）。
4. 在 Console 里搜 `[HYC Settings]` → 不应有「签名必须是无参 void」或「路径为空」的告警。
5. 触发一次域重载（改任意脚本）→ 分组与选中页保持。
