> ✅ **状态**：共 21 篇，全部基于仓库源码实测撰写（先读源码再写，不编造）。每篇深度 = 架构 + 关键类 + 用法 + 坑。最后更新：2026-09-13。

---

## 🤖 关于这份文档：专门为 AI 而写

本目录文档的目标读者**既包括人，也包括 AI** —— 写作时专门做了「AI 友好」处理：

- **结构固定**：每篇统一为「架构 → 关键类 → 用法 → 坑」四段式，AI 能快速定位所需上下文；
- **基于源码实测**：全部先读源码再落笔，不编造 API，AI 引用时不易产生幻觉；
- **关键信息内联**：类型全名、命名空间、菜单路径、约束条件都写在正文里，
  AI 无需遍历整个仓库即可给出准确答案。

**怎么用**：把 `docs/` 整个目录提供给 AI 助手（Copilot / WorkBuddy / Cursor 等），
或让它直接读某个主题的文档，AI 就能在不通读源码的情况下理解并正确修改本框架。

> 💡 这也是本项目开源的一部分：让 AI 能和人类一样低成本地上手这套框架。
