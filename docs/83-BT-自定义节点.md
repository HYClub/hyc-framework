# 83 · BT 自定义节点

## 机制

游戏层继承 `BTCustomNode` 写自己的节点逻辑；**编辑器自动扫描所有子类并注册，无需手动注册**，节点库下拉与参数面板会自动出现。

运行期由 `GameCustom` 节点（`BTNodeType.GameCustom = 128`）承载，`Long[0]` 存 `SubType`，解释器通过 `BTContext.GameHandler` 派发到 `BTNodeRuntimeRegistry`（反射缓存的子类实例）。

---

## 实现一个自定义节点

```csharp
public class FindNearestEnemy : BTCustomNode
{
    public override long SubType => 1001;                 // 同 TreeKind 内唯一
    public override string NodeName => "找最近敌人";
    public override BTCustomNodeKind Kind => BTCustomNodeKind.Action;
    public override BTTreeKind TreeKind => BTTreeKind.AI;
    public override string Description => "把最近敌人写入黑板";

    public override BTNodeState Execute(ref BTContext ctx, ref BTNodeView view)
    {
        // 读参数（支持字面值 or 黑板变量两种来源）
        float range = view.GetFloatVar(0);

        // ... 业务逻辑 ...
        return BTNodeState.Success;   // 未完成返回 Running
    }

    public override void OnStop(bool interrupted)
    {
        // 被中断/复位时的清理（释放占用、取消动画、停定时器）
    }
}
```

### 必须实现的成员

| 成员 | 说明 |
| --- | --- |
| `SubType` (`long`) | 子类型 ID，**同 `TreeKind` 内唯一** |
| `NodeName` (`string`) | 显示名 |
| `Kind` (`BTCustomNodeKind`) | `Condition` / `Action` / `Composite` |
| `Execute(ref BTContext, ref BTNodeView)` | 执行逻辑，返回 `BTNodeState` |

### 可选重写

| 成员 | 默认 | 说明 |
| --- | --- | --- |
| `TreeKind` | `Other` | 所属树类型（`Skill` / `AI` / `Other`） |
| `Description` | `""` | 说明，显示在节点上 |
| `Params` | `null` | `BTGameNodeParamDesc[]`，编辑器据此渲染输入/下拉 |
| `OnStop(bool interrupted)` | 空 | 从 Running 被复位/中断时调用 |

---

## `BTCustomNodeKind`

| 值 | 语义 | 样式 |
| --- | --- | --- |
| `Condition = 1` | 条件：立即判定返回 `Success` / `Failed`，**不返回 Running**；需要取反就套 `Invert` 节点 | 红 |
| `Action = 2` | 动作：每次 `Execute` 推进一小步，未完成返回 `Running`，完成返回 `Success` / `Failed` | 绿 |
| `Composite = 3` | 组合：有子节点、动态端口 | 蓝 |

### 叶子范式（对齐 NodeCanvas）

- **Action** 对应 `ActionTask`：跨帧进度存**黑板或本节点参数**，不需要协程——驱动系统每帧都会 Tick。
- **Condition** 对应 `ConditionTask`：只判定、不推进，`invert` 语义由 `Invert` 节点提供。

---

## 参数：字面值 or 黑板变量

用 `view.GetFloatVar(index)` / `view.GetIntVar(index)` 读参数，**同一个槽位既可以是字面值也可以是黑板键**（对应 NodeCanvas 的 `BBParameter<T>`）。

参数定义通过重写 `Params` 提供 `BTGameNodeParamDesc[]`，编辑器据此渲染输入框/下拉。

---

## 自动注册链路

```
BTCustomNode 子类
    ↓  BTCustomNodeScanner（Editor，扫描所有程序集）
BTGameNodeRegistry.Register(TreeKind, SubType, info)
    ↓  运行期
BTNodeRuntimeRegistry（反射缓存实例）← BTContext.GameHandler 分发
```

- 扫描器：扫描 `typeof(BTCustomNode).IsAssignableFrom(t)` 的类型并实例化注册
- 注册失败会打 `LogWarning`：`[BT] 自定义节点 {类型名} 注册失败: {原因}`
- 运行期查询：`BTGameNodeRegistry.TryGet(kind, subType, out var info)`

## 代码生成

节点库面板底部有 **`＋ 新建自定义节点…`** 按钮（`BTNodeCreatorWindow`），会生成模板代码：

```csharp
public class {ClassName} : BTCustomNode
{
    public override long SubType => #{subType};
    public override string NodeName => "...";
    public override BTCustomNodeKind Kind => BTCustomNodeKind.Action;
    public override BTTreeKind TreeKind => BTTreeKind.{Skill|AI|Other};
    public override BTNodeState Execute(ref BTContext ctx, ref BTNodeView view)
    {
        // TODO: 实现逻辑, 返回 BTNodeState.Success / Failed / Running
        return BTNodeState.Success;
    }
}
```

生成成功会打日志：`[BT] 已生成自定义节点 {路径} (子类型 #{subType})`。

## `BTCustomNodeContext`（可选）

游戏层可注入自己的世界数据供节点读取：

```csharp
public class BTCustomNodeContext
{
    public object Data;                                     // 游戏层自定义世界数据
    public Func<ulong, float> GetBlackboardFloat;           // 黑板快捷读
    public Action<ulong, float> SetBlackboardFloat;
}
```

节点在 `Execute` 里对 `Data` 做 cast 使用（例如强转成战斗世界的单位/属性数组容器）。

## 注意事项 / 坑

1. **`SubType` 必须在同 `TreeKind` 内唯一**——重复会被覆盖，且不一定有明确报错。
2. **含 `GameCustom` 节点的树走托管路径**（委托 + 反射），**不参与 Burst 编译**；纯内建节点的树才是指针遍历、无托管分配。
3. **`Condition` 不要返回 `Running`**——语义上不允许，会让 `Sequence` / `Selector` 卡住。
4. **`OnStop` 只在从 Running 被复位/中断时调用**，正常 `Success` / `Failed` 结束不会触发；清理逻辑别只写在 `Execute` 末尾。
5. **跨帧状态不要存在节点实例的字段上**——实例是共享缓存的（注册表里一份），跨帧进度写黑板或节点参数池。
