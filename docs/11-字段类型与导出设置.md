# 11 · 字段类型与导出设置

> 对应 `Runtime/ConfigTemplate.cs`。这是配置管线里最需要细读的一章——字段怎么落到 Blob，全看这里的设置。

---

## 一、字段类型 `ConfigFieldType`（45 种）

### 基础类型（11）
`String` `Int` `Long` `Float` `Double` `Bool` `Short` `Byte` `UInt` `Char` `Decimal`

### Unity 资源引用（11）
`Sprite` `Texture2D` `GameObject` `AudioClip` `Material` `Mesh` `PhysicMaterial` `Font` `Shader` `TextAsset` `Object`

### 数学 / 结构体（16）
`Vector2` `Vector3` `Vector4` `Vector2Int` `Vector3Int` `Quaternion` `Color` `Color32` `Rect` `RectInt` `RectOffset` `Bounds` `BoundsInt` `Gradient` `AnimationCurve` `LayerMask`

### 框架扩展（7）

| 类型 | 存储 / 生成 | 说明 |
| --- | --- | --- |
| `Enum` | 引用 `ConfigEnumDefinition.className` | 需填 `enumRefClassName` |
| `LocalizedKey` | 生成 `string` + `[LocKey]` | 多语言 key，需配合 loc 包 |
| `Reference` | 引用另一个 `[CfgAsset]` 类型 | 需填 `refTypeFullName`（Assembly-qualified） |
| `BehaviourTree` | 存 `BTTreeAsset.TreeId`（`long`） | 运行期经 `BTManager` 加载执行 |
| `AnimationClip` | 拖 `.anim`，生成 `AnimationClip` 字段 | — |
| `AnimatorController` | 拖 `.controller`，生成 `AnimatorController` 字段 | — |
| `Addressable` | **拖资源自动填地址，生成 `string`** | 运行期按地址加载 |

## 二、导出目标 `ConfigExportTarget`

| 值 | 含义 |
| --- | --- |
| `Client` | 只进客户端产物 |
| `Server` | 只进服务端产物 |
| `Both` | 两侧都要（默认） |

> 服务端拿不到的字段填 `Client`，可以减小服务端数据体积、也避免把客户端资源信息下发。

---

## 三、导出设置 `ConfigFieldExportSetting`

每个字段有**两套**导出设置：`clientExport` 和 `serverExport`——同一字段在两侧可以取不同值、不同类型表示。

### `ConfigFieldExportMode`（8 种）

| 模式 | 效果 |
| --- | --- |
| `Direct` | 原样导出（按字段自身类型/对象） |
| `ToString` | 数值/布尔/枚举/结构 `ToString()`，导出 `string` |
| `BlobString` | 字符串在 Blob 里用 `BlobString`（**变长**，由 BlobBuilder 分配） |
| `FixedString` | 字符串在 Blob 里用 `FixedString`（**定长内联**，容量见下） |
| `Member` | 配置引用字段导出它的某个标量成员（如 `ID` / `GUID`），填 `memberName` |
| `AssetName` | 资源/对象字段导出**资源名**（`string`） |
| `AssetPath` | 资源/对象字段导出**项目内路径**（`Assets/...`，`string`，导出时解析） |
| `AssetAddressable` | 资源/对象字段导出 **Addressable 地址**（`string`，导出时解析） |

辅助属性：

```csharp
setting.IsDirect       // mode == Direct
setting.IsStringValue  // BlobString 或 FixedString
```

### `ConfigFixedStringSize`（定长档位）

`Size32` `Size64` `Size128`（默认） `Size512` `Size4096`

对应 `Unity.Collections.FixedString{size}Bytes`。

> **怎么选**：名称/短文本用 64～128；描述性长文本用 512 或 4096；超长或长度差异极大的用 `BlobString`（变长，省空间但有间接寻址）。**定长会按最大容量占位**，别所有字段都给 4096。

## 四、检查规则

三个规则各自带级别，`None` 表示不启用：

| 字段 | 规则 |
| --- | --- |
| `notEmptyCheck` | 非空 |
| `notZeroCheck` | 非 0 |
| `rangeCheck` | 落在范围内（配合 `hasRange` / `minValue` / `maxValue`） |

级别 `ConfigCheckLevel`：`None` < `Info` < `Warning` < `Error`。

设置 `Error` 会让校验不通过（进而阻断导出），`Warning` 只提示。

## 五、`ConfigTemplateField` 字段一览

| 字段 | 说明 |
| --- | --- |
| `name` / `description` | 字段名 / 说明 |
| `type` | `ConfigFieldType` |
| `isList` | 是否为列表 |
| `refTypeFullName` | 仅 `Reference`：被引用配置类型的 Assembly-qualified 名 |
| `enumRefClassName` | 仅 `Enum`：`ConfigEnumDefinition.className` |
| `exportTarget` | 客户端 / 服务端 / 两者 |
| `hasRange` / `minValue` / `maxValue` | 数值范围 |
| `notEmptyCheck` / `notZeroCheck` / `rangeCheck` | 检查规则级别 |
| `clientExport` / `serverExport` | 两侧各自的 `ConfigFieldExportSetting` |

## 六、典型组合

| 场景 | 设置 |
| --- | --- |
| 装备名（多语言） | 类型 `LocalizedKey`，`clientExport = FixedString(Size128)` |
| 长描述文本 | 类型 `String`，`BlobString`，`Size4096` 浪费就用 `BlobString` |
| 图标 | 类型 `Sprite`，`clientExport = AssetAddressable`（生成地址字符串，运行期按地址加载） |
| 关联另一张表的行 | 类型 `Reference` + `refTypeFullName`，或 `Member` 模式只导出对方的 `ID` |
| 引用的行为树 | 类型 `BehaviourTree`（存 `TreeId`） |
| 只在客户端用的表现字段 | `exportTarget = Client` |
| 服务端校验用的关键数值 | `notZeroCheck = Error` + `rangeCheck = Error` |

---

## 注意事项 / 坑

1. **字符串必须显式选 `BlobString` 或 `FixedString`**，`Direct` 会把托管 `string` 带进 Blob 导致烘焙失败。
2. **`Reference` 要填完整的 Assembly-qualified 类型名**，填错会在生成/导出阶段报错，且错误信息不一定直观。
3. **改 `exportTarget` 或导出模式后必须重新导出**，否则产物还是旧的。
4. **`FixedString` 溢出会静默截断**——容量选小了不会报错，只会丢字，长文本务必留余量。
5. **`AssetPath` 依赖项目内路径**，资源挪动后旧数据不会自动更新；跨工程复用优先用 `AssetAddressable`。
