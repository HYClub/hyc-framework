# 20 · 多语言（Localization）总览

## 职责

把策划维护的 Excel 文案表，在**生成期**烘焙成 Blob 文件，运行期由静态管理器按 key 取当前语言文本，并驱动 UI 组件自动刷新。

命名空间：**`HYC.Framework.Loc`**（配置侧的 key 标记特性在 `HYC.Framework.Config`）。

一句话：**编辑期是 Excel，产物是 StreamingAssets 下的 Blob，运行期只有两个 Dictionary 查表。**

---

## 全链路

```
① Excel（.xls/.xlsx，默认 Assets/Localization）
   首行 = 表头（必须有 id 列，其余列按语言代码归一化）
        ↓  HYC Framework/Localization/Import Excel（NPOI 读取）
② 产物目录（默认 Assets/StreamingAssets/Localization）
   id          Blob: BlobArray<BlobString>   所有 key（顺序即索引）
   cn.lang     Blob: BlobArray<BlobString>   中文文本，与 id 同序
   en.lang     ...                           英文文本
   lang        纯文本                         默认语言代码（如 "en"）
   filter      Blob: BlobArray<BlobString>    敏感词表
   debug_ids   Blob: BlobArray<int>          【仅编辑器】key → Excel 文件索引
   debug_names Blob: BlobArray<BlobString>   【仅编辑器】Excel 文件名列表
        ↓  运行期 LocalizationBlobSystem（BeforeSceneLoad）
③ LocalizationManager.Reload(folder)
   mIDs / mLangs / mTexts[][] + mKey2Index / mLang2Index
        ↓
④ LocalizationManager.GetText(key)  →  LocalizedBase 组件 / 业务代码
```

## 核心类

| 类 / 文件 | 位置 | 职责 |
| --- | --- | --- |
| `Locale` | Runtime | 语言枚举：`Default=0` / `Chinese=1` / `English=2` / `Japanese=3` / `Korean=4` |
| `LocaleUtil` | Runtime | 语言代码 ↔ 枚举 ↔ Excel 表头归一化（`ToCode` / `FromCode` / `NormalizeLangHeader`） |
| `LocalizationManager` | Runtime | 静态管理器：加载、语言切换、查文本 |
| `LocalizationBlobSystem` | Runtime | `SystemBase`，开机自动从 StreamingAssets 加载 |
| `CfgLocalization` / `CfgLocalizationIndex` | Runtime | Blob 结构：`BlobArray<BlobString>` / `BlobArray<int>` |
| `SensitiveWordManager` | Runtime | 敏感词 Trie 过滤（字符串扩展方法） |
| `LocalizationExtension` | Runtime | `ToLocal()` / `TMP_Text.SetKey()` 等便捷扩展 |
| `LocalizedBase` + 三个子类 | Runtime/Components | 挂在文本组件上自动刷新 |
| `LocalizedTextAttribute` | Runtime | 标记 string 字段为本地化 key（Inspector 画选择器 + 预览） |
| `LocKeyAttribute` | Runtime | **配置字段**标记（属 `HYC.Framework.Config`，不依赖 Loc 包） |
| `LocalizedExcelReader` | Editor | Excel → Blob 导入 |
| `LocalizationSettings` | Editor | 目录与默认语言（存 EditorPrefs） |

## 语言代码约定

| `Locale` | 代码 | Excel 表头可写 |
| --- | --- | --- |
| Default | `en` | —（兜底） |
| Chinese | `cn` | `中文` / `简体中文` / `简中` / `cn` / `zh` / `chs` |
| English | `en` | `English` / `en` / `us` |
| Japanese | `jp` | `日本語` / `日文` / `jp` / `ja` |
| Korean | `kr` | `한국어` / `韩文` / `kr` / `ko` |

另外 `繁體中文` / `繁中` / `tc` / `cht` 会归一化成 **`tc`**——这是一个**没有对应 `Locale` 枚举值**的代码，`LocaleUtil.FromCode("tc")` 会回落到 `Default`。产物文件名直接用归一化后的代码（`tc.lang`）。

未知表头**原样保留**（trim 后），所以自定义语种也能导，只是 `Locale` 枚举认不出来。

## 运行期 API

```csharp
// 语言
LocalizationManager.SetLanguage(Locale.Chinese);
LocalizationManager.SelectedLanguage = "cn";    // 直接给代码也行
var cur = LocalizationManager.CurrentLocale;    // → Locale.Chinese

// 查询
string s = LocalizationManager.GetText("ui/common/confirm");
string f = LocalizationManager.GetText("tip/level_up", 12, "Aria");  // string.Format 占位符
string e = LocalizationManager.GetTextByLang("ui/common/confirm", "en");
bool ok  = LocalizationManager.HasKey("ui/common/confirm");

// 扩展方法（等价）
string s2 = "ui/common/confirm".ToLocal();
tmpText.SetKey("ui/common/confirm");

// 切换监听
LocalizationManager.onLanguageChanged += OnLangChanged;

// 原始数据
string[] ids   = LocalizationManager.IDs;
string[] langs = LocalizationManager.Langs;
string[][] all = LocalizationManager.Texts;   // [langIndex][keyIndex]
```

### 语言解析优先级

`SelectedLanguage` 的 getter 顺序：

1. `ConfigLanguage`（导入时写进 `lang` 文件，默认 `en`）
2. 若 `DefaultLanguage` 非空 **且在 `Langs` 里存在** → 覆盖
3. 若 `SelectedLanguage` 非空 **且在 `Langs` 里存在** → 再覆盖

也就是说：**语言包里不存在的代码会被静默忽略**，不会报错，只会沿用上一级。

### 查不到 key 时的表现

| 情况 | 返回 |
| --- | --- |
| key 不存在 | `"未找到Key : {key}"`（中文，不是空串） |
| key 存在但该语言文本为空 | `"[{key 最后一段}]"`，如 `[confirm]` |
| key 为 null / 空 | `string.Empty`（`GetText` 直接短路，不查表） |

所以**空文案不会静默消失**——会显示成 `[xxx]`，方便定位漏翻。

## 文本组件

| 组件 | 目标 | 约束 |
| --- | --- | --- |
| `LocalizedText` | `UnityEngine.UI.Text` | `[RequireComponent(typeof(Text))]` + `[DisallowMultipleComponent]` |
| `LocalizedTMP` | `TMP_Text` | 同上 |
| `LocalizedTextMesh` | `TextMesh`（3D） | 同上 |

基类 `LocalizedBase` 行为：

- `Key` 字段带 `[InspectorName("本地化ID"), LocalizedText]`，Inspector 里是「文本框 + ▾ 选择器 + ◉ 预览」。
- `OnEnable` 订阅 `onLanguageChanged`，`OnDisable` 退订；`OnEnable`/`OnValidate` 都会立即 `Refresh()`。
- 子类只需实现 `Refresh(string text)` 把文本塞进目标组件。

```csharp
// 代码里动态改
GetComponent<LocalizedTMP>().SetKey("ui/common/confirm");
```

## 注意事项 / 坑

1. **产物必须落在 StreamingAssets 下**，否则打包后 `LocalizationBlobSystem` 读不到（它只读 `Application.streamingAssetsPath/Localization`）。改输出目录时会丢这一层。
2. **CJK 文本要靠自定义 `AllocateString`**——Unity 自带的 `BlobStringExtensions.AllocateString` 按 `Length * 2 + 1` 分配，中文 UTF-8 是 3 字节/字，会被截断。`LocalizedExcelReader` 里按真实 UTF-8 字节数 + 1（null 结尾）手写分配，**不要换回内置方法**。
3. **`Locale` 是 byte 级的小枚举，但没有写死序列化顺序**——真正稳定的是语言**代码字符串**（`cn`/`en`/`jp`/`kr`），跨系统传递用代码，别传枚举数值。
4. **编辑器专用的 `debug_ids` / `debug_names` 只在 `UNITY_EDITOR` 下读写**；包体里不会有，也不要在运行时代码里访问 `ExcelNames` / `IDExcelNameIndexs`。
5. **`GetText(key, args)` 走 `string.Format`**，文案里 `{0}` 索引写错会 `LogException` 并返回未格式化原文，不会崩。
6. **切换语言只通知订阅者**——自己写的文本（非 `LocalizedBase` 组件）必须挂 `onLanguageChanged` 手动刷新。
7. **刷新异常被吞成 `Debug.LogError("刷新文字出错!")`**（`RefreshAll` 里 try/catch），某个组件抛异常不会中断其它组件。
