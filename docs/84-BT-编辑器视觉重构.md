## 关键实现（类与方法）

### `BTEditorStyles.cs`

- 圆角纹理：`RoundedBoxTexture`（9-slice 白色圆角方块，由 `GUI.color` 染色）+ `RoundedBoxStyle` + `DrawRounded(Rect, Color)` + `DrawRoundedCard(Rect, borderColor, fillColor, borderWidth)`。
- 圆形绘制：`DrawCircle(Vector2, float, Color)`、`DrawPortDot(Vector2, float, Color ring, Color fill)`、`DrawConnEnd(Vector2, float, Color)`。
- 状态取色：`StatusColor(BTNodeState)`（运行/成功/失败）。
- 抗锯齿圆：`AACircleTexture`（64px、SDF 抗锯齿）替代原 `Circle.png`（硬边）。

### `BTGraphIMGUI.cs`

- `DrawGridScreen()`：点阵网格（2×2 圆点，主网格每 4 格加亮）。
- `DrawNode(BTNodeData, Event)`：双层柔和阴影 → 卡片 3 层同轮廓填充（描边环 → 类别色整卡 → 主体色自左 `STRIPE_W(5)` 起）→ 头部（类别圆点 + 标题 `ResolveTitle` + 副标题 `CategoryName`）→ 端口 → 右上状态角标。
- `DrawNodeParams(BTNodeData, Rect)`：inline 参数走紧凑 `_paramLabel`(10px) / `_paramField`(10px)。
- `DrawConnection(BTConnectionData)`：`BezierTexture` 染色 + 运行态染色 + 末端圆点。
- 端口几何：`OutCount(BTNodeData)`、`OutputPortPos(BTNodeData, int)`、`ChildCount`、`ChildIndex`、`InputPortPos`。
- 高度：`NodeContentHeight(BTNodeData)`（行高 18，含 1 行备注）。

相关常量（`BTGraphIMGUI.cs`）：`HEADER_H=24`、`CARD_R=12`、`BORDER_W=1.5`、`STRIPE_W=5`、`GLYPH=16`、`BADGE=14`、`PORT_GAP=22`、`PORT_SIZE=12`；`BTEditorStyles.cs`：`ROUND_TEX_SIZE=48`、`ROUND_CORNER=12`、`ROUND_SS=4`。

## 绘制流程（含多端口与运行态）

### 多端口横向展开（数据模型不变）
BT 仍是「**单输出端口 + N 子节点扇出**」。`OutCount = max(1, ChildCount(n))`；`OutputPortPos(n, i)` 的 x 坐标按子节点索引 `i` 横向展开：

```
x = center.x + (i - (cnt - 1) / 2f) * PORT_GAP   // 底边居中、固定 PORT_GAP=22 间隔
```

视觉上呈「多端口」，但 `PortIndex` 不参与绘制顺序（改用列表序 `ChildIndex`）。连线/拖拽/命中测试逻辑**自动跟随**，未改交互逻辑。

### 运行态反馈
- 进入 Play 且 `BTManager.EditorDebugEnabled` 时，`BTManager.TryGetEditorLiveStates(_asset.TreeId, out liveStates)` 取每节点状态。
- 右上角标（`DrawStatusBadge`）：▶ 运行中（脉冲）/ ✓ 成功 / ✕ 失败。`EditorApplication.timeSinceStartup` 是 `double`，脉冲需 `(float)` 强转。
- 连线按**源节点**运行态染色（`StatusColor`），状态沿树流动。

## 抗锯齿修复（关键）

**根因**：旧 `RoundedBoxTexture` 每像素只有二值 alpha（`inside ? 255 : 0`），边缘无灰度过渡 → 1:1 即楼梯锯齿，缩放更严重（与分辨率/过滤无关）。

**修复**：
- `RoundedBoxTexture` 重写为 **4× 超采样 + 圆角矩形 SDF（符号距离场）算连续 alpha + 盒式降采样回 48px + mipmap**（`Apply(true, false)`），边缘过渡带约 0.5 最终像素。SDF：

```
q = |p| - (half - r)          // p 相对中心，half = 纹理半边，r = 角半径(高分辨率)
sd = length(max(q, 0)) + min(max(qx, qy), 0) - r
alpha = clamp01(0.5 - sd * 0.5)   // 2 hi-res px 过渡带，居中边界
```

- `AACircleTexture`：64px 圆形 SDF（约 1.4px 过渡带）替换 `Circle.png` 硬边；`DrawCircle/DrawPortDot/DrawConnEnd` 全部切换。

## 坑 / 注意事项

1. **二值 alpha 必锯齿**：IMGUI 程序生成几何纹理（圆角/圆/任意形状）必须用 SDF 或超采样产生**连续 alpha**；否则边缘楼梯，与分辨率、过滤模式无关。
2. **9-slice 圆角半径一致性**：`GUIStyle.border` 的像素必须对应纹理内圆角弧所占像素，且纹理 corner 半径 = `ROUND_CORNER`(12)。超采样要先在**高分辨率**算 SDF 再降采样回原始尺寸——否则 border 只裁到弧的一部分，圆角被切平。
3. **`EditorApplication.timeSinceStartup` 是 `double`**，喂 `Mathf.Sin` 必须 `(float)` 强转，否则 `CS1503: cannot convert from 'double' to 'float'`。
4. **旧 NodeCanvas 样式已弃用**：新渲染全走 `DrawRounded`/`DrawCircle`/`DrawPortDot`/`DrawConnEnd`；改视觉只动这几个辅助，不要回去用 `NodeBodyStyle` 等。
5. **文档放仓库根 `docs/`（包外）**：不要放 `com.hyc.framework/Editor/BT/` 内——否则会被 Unity 当资源导入，且不符合本仓库文档约定。本文档即此类。
6. 连线仍走 `Handles.DrawBezier` + `Bezier.psd`（自带软边），无需改；新增几何纹理才需要走上面 1–2 的抗锯齿流程。
