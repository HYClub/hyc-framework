多语言 Localization

把策划维护的 Excel 文案表，在生成期烘焙成 Blob 文件，运行期由静态管理器按 key 取当前语言文本，并驱动 UI 组件自动刷新。

命名空间 HYC.Framework.Loc。一句话：编辑期是 Excel，产物是 StreamingAssets 下的 Blob，运行期只有两个 Dictionary 查表。

全链路

① Excel（.xls/.xlsx，默认 Assets/Localization）
   首行 = 表头（必须有 id 列，其余列按语言代码归一化）
        ↓  HYC Framework/Localization/Import/Excel (Import & Build Blob)（NPOI 读取）
② 产物目录（默认 Assets/StreamingAssets/Localization）
   id / cn.lang / en.lang / ...   BlobArray<BlobString>
   lang / filter / debug_ids / debug_names
        ↓  运行期 LocalizationBlobSystem（BeforeSceneLoad）
③ LocalizationManager.Reload(folder)
        ↓
④ LocalizationManager.GetText(key)  →  LocalizedBase 组件 / 业务代码

核心类

类 / 文件职责
Locale语言枚举：Default=0 / Chinese=1 / English=2 / Japanese=3 / Korean=4
LocaleUtil语言代码 ↔ 枚举 ↔ Excel 表头归一化
LocalizationManager静态管理器：加载、语言切换、查文本
LocalizationBlobSystemSystemBase，开机自动从 StreamingAssets 加载
SensitiveWordManager敏感词 Trie 过滤（字符串扩展方法）
LocalizedBase + 三子类挂在文本组件上自动刷新（LocalizedText / LocalizedTMP / LocalizedTextMesh）
LocalizedTextAttribute / LocKeyAttribute标记 string 字段为本地化 key（Inspector 画选择器 + 预览）

◈

运行期 API

// 语言
LocalizationManager.SetLanguage(Locale.Chinese);
LocalizationManager.SelectedLanguage = "cn";    // 直接给代码也行
var cur = LocalizationManager.CurrentLocale;    // → Locale.Chinese

// 查询
string s = LocalizationManager.GetText("ui/common/confirm");
string f = LocalizationManager.GetText("tip/level_up", 12, "Aria");  // string.Format 占位符
string e = LocalizationManager.GetTextByLang("ui/common/confirm", "en");
bool ok  = LocalizationManager.HasKey("ui/common/confirm");

// 扩展方法（等价）
string s2 = "ui/common/confirm".ToLocal();
tmpText.SetKey("ui/common/confirm");

// 切换监听
LocalizationManager.onLanguageChanged += OnLangChanged;

查不到 key 时的表现：key 不存在 → "未找到Key : {key}"；key 存在但文本为空 → "[{key 最后一段}]"（如 [confirm]）；key 为 null/空 → string.Empty。所以空文案不会静默消失，会显示成 [xxx] 方便定位漏翻。

文本组件

组件目标约束
LocalizedTextUnityEngine.UI.Text[RequireComponent(typeof(Text))] + [DisallowMultipleComponent]
LocalizedTMPTMP_Text同上
LocalizedTextMeshTextMesh（3D）同上

基类 LocalizedBase：Key 字段带 [InspectorName("本地化ID"), LocalizedText]，Inspector 里是「文本框 + ▾ 选择器 + ◉ 预览」。OnEnable 订阅 onLanguageChanged，语言切换时自动 Refresh()。代码里动态改：GetComponent<LocalizedTMP>().SetKey("ui/common/confirm");

常见坑

  • 产物必须落在 StreamingAssets 下，否则打包后 LocalizationBlobSystem 读不到（它只读 Application.streamingAssetsPath/Localization）。
  • CJK 文本要靠自定义 AllocateString：Unity 自带的按 Length * 2 + 1 分配，中文 UTF-8 是 3 字节/字会被截断。LocalizedExcelReader 按真实 UTF-8 字节数 + 1 手写分配，不要换回内置方法。
  • 真正稳定的是语言代码字符串（cn/en/jp/kr），跨系统传递用代码，别传枚举数值。
  • 编辑器专用的 debug_ids / debug_names 只在 UNITY_EDITOR 下读写，运行时代码不要访问。
  • GetText(key, args) 走 string.Format，{0} 索引写错会 LogException 并返回未格式化原文，不会崩。
  • 切换语言只通知订阅者——自己写的文本（非 LocalizedBase 组件）必须挂 onLanguageChanged 手动刷新。
