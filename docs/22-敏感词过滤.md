# 22 · 敏感词过滤

## 职责

基于 Trie（`Hashtable` 嵌套）的敏感词过滤，词表来自本地化管线的 `filter` 产物。提供三个**字符串扩展方法**：打码、校验、列举。

```csharp
using HYC.Framework.Loc;

bool bad   = "some text".Validate();          // 是否含敏感词
string out = "some text".Filter();            // 打码成 "**** text"
var words  = "some text".GetAllMaskWords();   // 命中的词列表
```

---

## 数据来源

```
Assets/Localization/filter.txt
  ↓  LocalizedExcelReader.ImportExcels()
  按 ',' '，' '\n' 切分 → Trim → 去空 → Distinct
  ↓  Save("filter", words)
StreamingAssets/Localization/filter   （Blob: BlobArray<BlobString>）
  ↓  LocalizationManager.Reload()
LocalizationManager.SensitiveWords    （string[]）
  ↓
SensitiveWordManager.Init()
```

`filter.txt` 缺失只是 `Debug.LogWarning`，**不会阻断导入**，此时 `SensitiveWords` 是空数组。

## Trie 结构

```csharp
// 根节点
mMaskWordTable: Hashtable  { '中' -> Hashtable, 'f' -> Hashtable, ... }
// 每个节点都带一个哨兵键
new Hashtable { { "IsEnd", 0 } }     // 0 = 不是词尾，1 = 是词尾
```

构建（`InitSensitiveWordMap`）：

- 逐词逐字符下沉；节点不存在则新建带 `IsEnd=0` 的子表。
- **符号字符直接 `continue` 跳过**（`IsSymbol`），所以词表里写 `f*u*c*k` 也能匹配 `fuck`。
- 词的最后一个有效字符处理完，把当前节点 `IsEnd` 置 1。

⚠️ 副作用：如果某个词的**最后一个字符是符号**，`IsEnd` 会打在倒数第二个有效字符的节点上——词表尽量别以符号结尾。

⚠️ 空词 `""` 会创建出一堆无意义节点但不会崩。

## 匹配规则

`SearchSensitiveWord(text, startIndex)` 从 `startIndex` 贪心最长匹配：

```csharp
for (int i = startIndex; i < text.Length; i++)
{
    char word = text[i];
    if (IsSymbol(word)) { len++; continue; }          // 符号跳过但计入长度
    var temp = (Hashtable)newMap[word]
            ?? (Hashtable)newMap[char.ToLower(word)]   // 大小写回退
            ?? (Hashtable)newMap[char.ToUpper(word)];
    if (temp != null) { flag = (int)temp[END_FLAG] == 1; newMap = temp; len++; }
    else break;
}
return flag ? len : 0;    // 没走到词尾返回 0
```

### 三段式后处理（三个 API 共用）

命中一段后还要过一次「全字母判定」：

```csharp
if (IsAllLetters(input))                       // 命中片段全是英文字母
{
    if ((i + len < value.Length && IsAllLetters(value[i + len]))   // 右邻是字母
     || (i > 0 && IsAllLetters(value[i - 1])))                     // 左邻是字母
        isChange = false;                      // 判为误命中，跳过
}
```

**目的**：词表里有 `ass` 时，不会把 `class` / `pass` / `bass` 打码。
**代价**：中文词不受影响（`IsAllLetters` 对 CJK 返回 false，因为 `char.IsLetter` 对汉字其实返回 true……注意下面这条）。

⚠️ `IsAllLetters(string)` 用的是 `char.IsLetter(c)`——**汉字也算 letter**。所以纯中文命中片段若左右邻是汉字，也会被判为误命中而放过。中文词表里**不要放会被更长中文词包含的词**（例如放了"敏感"而文本是"敏感度"，会漏）。

## API 细节

| 方法 | 返回 | 说明 |
| --- | --- | --- |
| `Init()` | void | 从 `LocalizationManager.SensitiveWords` 重建 Trie |
| `Clean()` | void | 清空并置 null |
| `Filter(this string)` | string | 命中片段逐字符替换成 `*`，返回新串 |
| `Validate(this string)` | bool | 任一命中即 `true`（过全字母判定后） |
| `GetAllMaskWords(this string)` | `List<string>` | 所有命中片段原文 |

- 三者都是**懒初始化**：`mMaskWordTable == null` 时自动 `InitSensitiveWordMap(LocalizationManager.SensitiveWords)`。
- 命中后 `i += length - 1`（配合 for 的 `i++` 实现跳过），不会重复匹配同一段。
- `Filter` 用 `StringBuilder(text)` 原地改字符，**保留原文长度**（打码后长度不变，适合有字数限制的 UI）。
- `Filter("")` / `Filter(null)` → `string.Empty`。
- ⚠️ `Validate` / `GetAllMaskWords` **没有 null 检查**，传 null 会 NRE；调用前自己判空。

## 用法建议

```csharp
// 玩家改名提交前
if (!string.IsNullOrEmpty(input) && input.Validate())
{
    var hits = input.GetAllMaskWords();
    ShowTip($"包含敏感词：{string.Join("、", hits)}");
    return;
}
SaveName(input);

// 聊天展示（只打码不拦）
chatLabel.text = message.Filter();
```

**服务端必须再校验一次**——客户端 Trie 可以被绕（符号跳过、大小写回退都能构造绕过），`Filter` 只适合展示层。

## 注意事项 / 坑

1. **`Init()` 只由外部显式调用**；真正常用的是懒初始化。但**换过词表后必须手动 `Clean()` 或重新 `Init()`**，否则 Trie 里还是旧词（`Filter` 看到 `mMaskWordTable != null` 就不会重建）。
2. **`Reload()` 不会通知 `SensitiveWordManager`**——导入新敏感词后要自己 `SensitiveWordManager.Clean()`。
3. **符号被吞**：`IsSymbol` 把空格、标点、以及**所有不在 0x2E80–0x9FFF 的非字母数字字符**都当符号跳过。所以 `"f u c k"`、`"f-u-c-k"` 都能命中 `fuck`——这是特性，但也会造成误判（如词表有 `abc`，`a.b.c` 会中）。
4. **大小写回退依赖 `char.ToLower/ToUpper`**，非拉丁字母（如德语 ß、土耳其 İ）行为以 .NET 规则为准。
5. **词表 O(n) 构建 + O(L) 匹配**（L 为文本长度），适合几千词的量级；十万级请换成 DFA/AC 自动机。
6. **Trie 用 `Hashtable` 而非泛型 Dictionary**，主线程专用，**不要在 Job/Burst 里调用**。
