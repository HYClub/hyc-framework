组件绑定 UI Binder

把预制体上的节点 / 组件在开发期登记下来，生成强类型 Binder 类，窗口代码里用 Binder.CloseButton 直接访问——告别 transform.Find("...") 字符串。

运行时协议在 HYC.Framework.UI；生成类命名空间默认取项目设置的 CodeOutputPackageName。

三步接入

1. 预制体上挂 ComponentBinderTable    Add Component → HYC Framework/UI/UI 元素绑定
   逐条登记 Name / Target / Component / Desc
2. 生成                           菜单 HYC Framework/UI/Generate UI Binders
3. 窗口里用                        Binder.CloseButton.onClick.AddListener(...)

嵌套 Binder（列表项）也是这样生成的：

// 字段
private UI.BagItemBinder m_Item__;
// 构造

// 属性
public UI.BagItemBinder Item => m_Item__;

运行时路径解析工具

using HYC.Framework.UI;

// 按路径取组件（path 为空则取 root 自身）
var btn = BinderEngine.Get<Button>(root, "Panel/Left/Close");

// 约定式：下划线转斜杠
var icon = BinderEngine.FindBySeralized<Image>(root, "Panel_Left_Icon");
// 等价于 Get<Image>(root, "Panel/Left/Icon")

// 直接实例化并绑定一个 Binder
var binder = BinderEngine.Bind<BagBinder>(rootGameObject);

坑

  • 默认类名取 GameObject 名——中文 / 空格节点名会生成失败（Invalid class name）。给绑表所在节点起个英文名字，或开 CustomClassName。
  • 每次 GenerateAll 会清空输出目录里所有带标记的文件：CleanFolder 按首行 // ComponentBinder 判断，不要把手写代码放进这个目录。
  • 输出目录是每工程设置（ProjectSettings/ComponentBinder.asset，无框架默认值）——建议指向 Assets/HYC/Generated/UI/Binders/，与配置 / 属性 / 天赋 / BT 产物归在一处。
  • ComponentBinderTable 会随预制体进包，条目多会增加序列化体积，按需登记。
  • 属性不缓存，高频访问（每帧）的组件建议自己在 OnViewOpen 里缓存到字段。
  • Require<T> 目前只是 Get<T> 的别名，不会报错（名字有误导性，别指望它抛异常）。
