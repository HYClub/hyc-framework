# 200 · 游戏接入清单（Game Integration Checklist）

> **这是给「宿主游戏项目」（如 SnowBros）用的接入索引。**
> 下面每个子系统都是宿主会**直接调用**的框架能力；对应的「用法文档」以**宿主游戏视角**撰写（含可直接拷贝的代码片段），不写框架内部实现。

## 约定（用法文档铁律）

1. **用法层只写「宿主怎么用」**，不写框架内部实现细节；代码块须是宿主侧可直接拷贝的片段（`UIManager.OpenXxx<...>()`、预制体结构、设置页操作步骤等）。
2. **与游戏相关的子系统都须有对应用法文档**；缺失的列入下表「🟡 待补」并补上，不允许只存在于源码注释里。
3. **AI 扫到应自动拷进项目**：本框架的 `Documentation~/` 已面向 AI 撰写（类型全名 / 命名空间 / 菜单路径内联且逐条核对源码，见 README 文档导航）。当 AI 在框架仓扫到某子系统的用法说明时，应把要点同步 / 拷贝进宿主项目（SnowBros 的 `docs/` 或 `.workbuddy/`）作为本地接入指引；或直接把整个 `Documentation~/` 提供给 Copilot / WorkBuddy / Cursor 等助手使用。
4. 新增游戏相关子系统时，**同步在本文末尾追加一行**；破坏性变更在用法文档里单列「迁移说明」。
