通用属性配置系统 · 基础版原型

路线 A 配置表驱动 编辑时怎么配 + 代码里怎么用（可交互演示）。数据只在浏览器内，不会保存。

属性系统 = 一张属性目录（配置表生成的 AttributeDef 行）+ 每个实体自己引用其中若干条。 框架只认 key + 类型 + 默认/上下限，不认识 "HP/ATK" 是什么。

属性目录（= AttributeDef 配置行）

现实中由配置管线（Excel/模板）生成；这里直接展示它长什么样、能在编辑器里改什么。

key类型默认minmax显示名

实体 → 引用哪些属性

"每个实体有每个实体的属性" = 勾选它引用目录里的哪几条。运行时按这条清单初始化它的属性袋。

对应到框架代码： 目录的每一行 = 一个 AttributeDef 配置行（实现接缝接口 IAttributeDef）； 实体勾选的清单 = 一串 ConfigRowRef（typeName + id），交给 AttributeInitializer.Init<T>(em, entity, refs) 初始化属性袋，默认值按 [min,max] 钳制。

1) 配置侧：属性目录的一行（由使用方用管线生成）

// 框架只定义接缝接口，不认识具体属性名；使用方生成的配置行去实现它
public interface IAttributeDef {
    string Key { get; }
    AttributeType ValueType { get; }
    long DefaultRaw { get; }   // Float 用 IEEE754 bits 存进来
    long MinRaw { get; } long MaxRaw { get; }
}

// 配置管线生成的行（示意：HP / ATK / MoveSpeed / IsBoss）
public struct AttrConfig : IAttributeDef {
    public long id;                 // ConfigId
    public string Key => "HP";
    public AttributeType ValueType => AttributeType.Int;
    public long DefaultRaw => 100;
    public long MinRaw => 1;   public long MaxRaw => 9999;
}

2) 运行期：初始化一个实体的属性袋

// 实体上挂 DynamicBuffer<AttributeValue>；用它对引用的属性目录行初始化
List<ConfigRowRef> refs = new List<ConfigRowRef> {
    new ConfigRowRef { typeName = "HYC.Framework.Config.Generated.AttrConfig", id = hpId },
    new ConfigRowRef { typeName = "HYC.Framework.Config.Generated.AttrConfig", id = atkId },
    new ConfigRowRef { typeName = "HYC.Framework.Config.Generated.AttrConfig", id = spdId },
};
AttributeInitializer.Init<AttrConfig>(entityManager, heroEntity, refs);

3) 运行期：按 key 读写（key 自动 FNV-1a 哈希，与 BT 同算法）

int atk = AttributeStore.GetInt(em, heroEntity, "ATK");
AttributeStore.SetInt(em, heroEntity, "ATK", atk + 10);      // 超 max 自动钳制
float spd = AttributeStore.GetFloat(em, heroEntity, "MoveSpeed");
AttributeStore.SetFloat(em, heroEntity, "MoveSpeed", 8.0f);
