HYC Framework

框架能力
数据

配置系统 Config →

Excel / 模板 → 代码生成 → 数据编辑器 → 导出 Blob → 门面查询。全程类型安全、零字符串键，发号服强制派发 ID。

 数据

多语言 Localization →

Excel 文案表烘焙为 Blob，运行期按 key 取文本，界面组件自动刷新。

 逻辑

行为树 BT →

可视化编辑行为树 → 导出 Blob → ECS 逐帧驱动实体 AI，TreeId 本机派生跨机隔离。

 表现

ECS UI →

窗口即 System，层级表驱动、Addressables 实例化、焦点与模态，最后刷新不抢玩法帧。

 表现

音频 Audio →

引用格式决定路由（clip:/wwise:），统一播放门面，后端可切换。

 数据

通用属性 Attr →

配置表驱动的属性清单，代码生成 AttrKey 枚举 + 类型安全读写 Bag。
三行代码跑通
// 1. 跨端统一入口：WebGL / Android 先把数据预取进内存，PC / iOS 是 no-op
await new FrameworkBootstrap().InitializeAsync("Game World");

// 2. 打开一个 UI 窗口（窗口即 ECS System，异步就绪）
UIManager.OpenWindow<BagWindow>(1001);

// 3. 查配置：门面是唯一入口，必须 ref 接收（EA0001 铁律）
ref var row = ref ConfigManager.ItemRow.GetByID(1001);

完整接入方式见 引导与世界 · 按任务查配方见 操作手册
