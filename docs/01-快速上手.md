# 01 · 快速上手

> 给第一次接手 HYC Framework 的人。先建立全景，再知道"东西在哪、怎么跑起来"。详细机制看各模块文档（见文末索引）。

---

## 一、这是什么

HYC Framework 是一个 **Unity 2022.3 + DOTS/ECS 数据驱动**框架：

- 配置、本地化、行为树的**数据**在生成/编辑期烘焙成不可变 **Blob**；
- **UI 即 ECS System**（不是 MonoBehaviour 窗口管理器）；
- 世界由引导期组装，按固定阶段更新；
- 帧末清消息，单帧内流转。

代码位置：仓库的 [`com.hyc.framework/`](../com.hyc.framework) 子目录（包名 `com.hyc.framework`，`package.json` 在包根）。

---

## 二、数据流四阶段

```
[生成期] 模板/Excel/行为树资产 → 代码生成 + 数据编辑
   ↓
[A0/A1 引导期] 装单例、加载配置表、读启动参数 → 注册到 ConfigManager
   ↓
[A2/A3 运行期] 房间/场景、模拟、技能、AI、战斗
   ↓
[B9 表现期] UI 最后跑，读一帧前已算好的状态
```

更新组顺序固定：`A0 → A1 → A2 → A3 → B9`（都在 `UpdateGroup_Root` 下）。**UI 永远最后刷新**，所以玩法改的值下一帧 UI 才看到——这是设计，不是延迟。

## 三、5 分钟跑通一个窗口

```csharp
// 1) 建一个配置资产（数据编辑器里，详见 12 篇）
// 2) 引导期注册配置表
ConfigManager.Register(myTable);          // myTable 是 ConfigBlobTable<TRow>

// 3) 写一个窗口 System
public class BagWindow : BaseWindowSystem<BagBinder>
{
    public override string PrefabKey => "UI/BagWindow.prefab";
    public override void OnViewOpen(params object[] args)
    {
        base.OnViewOpen();
        Binder.CloseButton.onClick.AddListener(() => UIManager.Close<BagWindow>());
    }
}

// 4) 打开（异步！View 在 OnViewOpen 里才就绪）
UIManager.OpenWindow<BagWindow>(1001);

// 5) 查配置
if (ConfigManager.TryGet<ItemRow>(1001, out var row))
    Debug.Log(row.Name);
```

⚠️ **`UIManager` 是 `[DisableAutoCreation]`**——引导期必须手动建（见 60 篇）。没建就 `OpenWindow` 会空引用。

## 四、最小引导

```csharp
// 在自己的 ICustomBootstrap / MonoBehaviour 里
var host = new FrameworkWorld("Framework World");
World.DefaultGameObjectInjectionWorld = host.World;

// 把输入资产接进去（否则热键全失败）
HotkeyManager.BindAsset(myStartupSetting.InputActionAsset);

// 装 UI 管理器（手动，因为 FrameworkWorld 不会自动扫 DisableAutoCreation 系统）
host.World.GetOrCreateSystemManaged<UIManager>();

host.Install(installers, FrameworkBootstrap.Live);
// 每帧：host.Update();
```

或更简单——用 `FrameworkModeBootstrap().Initialize("Framework World")` 让它自己 `GetAllSystems` + 加进 player loop（不用手动 `Update`）。

## 六、最常见的 6 个坑

1. **打开窗口是异步的**——`Open<T>()` 返回时 `View == null`，初始化写在 `OnViewOpen`，别写 `OnCreate`。
2. **`OnViewClose` 一定要 `base.OnViewClose()`**——否则热键不注销、部件不关、焦点不配对。
3. **`PrefabKey` 必填**，`SceneKey` 可选；动作名找不到热键会 `LogError + ID=0` 无效句柄。
4. **`HotkeyManager.BindAsset` 必先做**，且别重复调（会重复订阅）。
5. **配置行必须 blittable**：`string` → `BlobString`/`FixedString`，`Vector3` → `Unity.Mathematics.float3`。
6. **`id == 0` 视为未分配**：配置资产 ID 从 1 起，复制资产后要重新派发。

## 七、编辑器入口速查

```
HYC Framework/
├─ Config/
│  ├─ Config Window          配置窗口（生成的类浏览器）
│  ├─ Data Editor            数据编辑器（填表，主力）
│  ├─ Generate Config         重新生成配置类
│  └─ (Tools/) Validate Config  结构校验
├─ Localization/
│  ├─ Import Excel            Excel → Blob
│  ├─ Settings               目录/默认语言/敏感词文件
│  ├─ Key Browser            浏览/导出 CSV
│  └─ Sensitive Words        敏感词测试台
├─ UI/
│  └─ Generate UI Binders    生成组件绑定类
└─ BT Editor                 行为树编辑器（Tools/HYC/BT Editor）
```

（完整菜单表见 [90 编辑器工具链](./90-编辑器工具链.md)。）
