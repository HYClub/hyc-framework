## ⚠️ 维护规则（改脚本必须遵守）

**任何一次对 `com.hyc.framework/` 下 `.cs` 文件的增 / 删 / 改名 / 移动，都必须同步更新本表。**

1. 改完代码后重跑下方脚本，覆盖本文件的表格部分；
2. 更新顶部「统计」里的文件数与类型数；
3. 若新增/删除了目录分组，同步改脚本里的 `GROUPS`；
4. 若文档篇数发生变化，同步改 [`docs/README.md`](./README.md) 的导航表与篇数。

不更新本表 = 索引失真 = 下次又要重新遍历全部文件，本表的意义就没了。

### 重新生成（复制整段运行即可）

```python
import os, re

ROOT = r"E:\Work-SD\hyc-framework\com.hyc.framework"   # 改成你的实际路径
OUT  = r"E:\Work-SD\hyc-framework\docs\100-文件与类索引.md"

TYPE_RE = re.compile(
    r"^[ \t]*(?:\[[^\]]*\][ \t]*)*(?:(?:public|internal|private|protected|static|sealed|"
    r"abstract|partial|readonly|unsafe|new)[ \t]+)*(class|struct|interface|enum|delegate)"
    r"[ \t]+([A-Za-z_]\w*)",
    re.M,
)
NS_RE = re.compile(r"^[ \t]*namespace[ \t]+([\w.]+)", re.M)

GROUPS = [
    ("Runtime", False), ("Runtime/Attributes", False), ("Runtime/BT", False),
    ("Runtime/Components", False), ("Runtime/ToolTip", False),
    ("Editor", False), ("Editor/BT", False), ("Editor/DataEditor", False),
    ("Editor/Loc/Editor", False),
]

lines, tf, tt = [], 0, 0
for rel, _ in GROUPS:
    d = os.path.join(ROOT, rel)
    if not os.path.isdir(d):
        continue
    files = sorted(f for f in os.listdir(d) if f.endswith(".cs"))
    if not files:
        continue
    tf += len(files)
    lines += ["", "### `%s/`（%d 个文件）" % (rel, len(files)), "",
              "| 文件 | 命名空间 | 类型 |", "| --- | --- | --- |"]
    for f in files:
        src = open(os.path.join(d, f), "r", encoding="utf-8-sig", errors="ignore").read()
        m = NS_RE.search(src)
        ns = m.group(1) if m else "—"
        kinds = []
        for mm in TYPE_RE.finditer(src):
            item = "`%s %s`" % (mm.group(1), mm.group(2))
            if item not in kinds:
                kinds.append(item)
        tt += len(kinds)
        lines.append("| `%s` | `%s` | %s |" % (f, ns, "、".join(kinds) if kinds else "—"))

print("表格已生成：files=%d types=%d（把 lines 写入 OUT，并记得更新顶部统计）" % (tf, tt))
```

> 脚本只生成表格部分；写回文件时请保留本文件顶部的说明与维护规则章节。
