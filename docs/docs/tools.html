菜单 priority 分档约定

⚠
每个叶子项都必须显式写 priority，否则默认 1000（不是 0）⇒ 沉底。
三档区间：内容 0–81 / 工具 100–102 / 项目 200–210。
相邻 priority 差 ≥ 11 才自动画分隔线（Unity 只在差值 ≥ 11 时画线：100 与 111 有、110 没有）。
父菜单顺序由其第一个子菜单的 priority 决定。

坑

  • Clean Missing Asset References 会直接改资产文件——跑之前确保工作区干净，方便回滚。
  • NPOI 只在编辑器可用——别在运行时代码里引用 LocalizedExcelReader 或 NPOI 类型。
  • DataEditor/ 大量字段抽屉依赖 ConfigFieldType——加新字段类型时，抽屉渲染要同步加分支，否则新类型在编辑器里显示不出来。
  • BT 编辑器是纯 IMGUI，没有 UXML/USS；改界面直接改 BTGraphIMGUI.cs 的绘制代码。
  • 画布不做 GUIClip 裁剪——新增任何面板 / 浮层都要画在画布之后，否则会被节点盖住或反过来盖住节点。
